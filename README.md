# 🎮 Minecraft 指令生成器

> 一款可视化 Minecraft 指令生成工具，支持 1.20.x ~ 1.21.x 多版本。

---

## 📥 下载安装

👉 **[点击此处下载最新安装包](https://github.com/mumu286/mc-command-generator/releases/latest)**

支持 Windows 系统，下载后双击安装即可使用。

---

## ✨ 功能特点

- 支持多个 Minecraft 版本（1.20.x ~ 1.21.x）
- 可视化生成 `/give` 指令
- 支持物品附魔、属性修改
- 一键复制生成的指令
